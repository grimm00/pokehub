### Bug: Date Format Test Fails Across Locales

**Location**: `frontend/src/__tests__/components/auth/UserProfile.test.tsx:220-227`

**Severity**: MEDIUM (test robustness issue)

**Description**: The test's regex for the user creation date expects a specific MM/DD/YYYY format with forward slashes. Since `toLocaleDateString()` produces varied locale-specific formats (e.g., with dots or dashes), this test is fragile and prone to failure in international environments.

**Root Cause**: Regex pattern `/\d{1,2}\/\d{1,2}\/\d{4}/` only matches forward-slash separators.

**Impact**: Test will fail in non-US locales (e.g., European date formats with dots or dashes).

**Recommended Fix**: Use a more flexible pattern that just checks for a 4-digit year.
