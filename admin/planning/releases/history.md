## Release Notes Format

Starting with v1.0.0, releases will follow this format:

### vX.Y.Z - Release Name (Date)

**Added**
- New features

**Changed**
- Changes to existing functionality

**Fixed**
- Bug fixes

**Improved**
- Performance and quality improvements

**Deprecated**
- Features marked for removal

**Removed**
- Removed features

**Security**
- Security updates
