## 💡 Known Considerations

### Design Decisions

1. **Mixed Testing Strategy**
   - Runtime tests for behavior validation
   - Structure tests for script content validation
   - Rationale: Avoids long sleep delays while maintaining coverage

2. **Pokehub-Specific Helpers**
   - Custom mocks for all Pokehub services
   - Custom assertions for Pokehub workflows
   - Rationale: Better test readability and maintainability

3. **Composite Mocks**
   - `mock_pokehub_services_healthy()` mocks all services at once
   - Rationale: Reduces boilerplate in tests

4. **Test Isolation**
   - Each test uses `setup()` and `teardown()`
   - Mocks are restored after each test
   - Rationale: Ensures tests are independent

## 🚀 Deployment Notes

### Prerequisites
- Bats must be installed (CI installs automatically)
- macOS: `brew install bats-core`
- Linux: `npm install -g bats`

### Running Tests
```bash
# Run all shell tests
./tests/shell/run-shell-tests.sh

# Run specific test
./tests/shell/run-shell-tests.sh -t unit/deployment/test-deploy.bats

# Verbose mode
./tests/shell/run-shell-tests.sh -v
```

### CI/CD
- Tests run automatically on push/PR to main/develop
- Shell tests run before other test jobs
- Test results uploaded as artifacts
