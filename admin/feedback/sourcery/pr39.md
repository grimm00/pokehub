### Comment 3: Extract Common Grep Assertions
**Issue:** Repeated grep patterns could be extracted to helper functions

**Sourcery Feedback:**
> You might extract common grep assertions into a helper function to reduce duplication and improve maintainability of the bats tests.

**Priority:** 🟢 LOW

**Analysis:**
- **Common patterns:**
  ```bash
  run grep "pattern" "$PROJECT_ROOT/scripts/..."
  [ "$status" -eq 0 ]
  ```

- **Could be:**
  ```bash
  assert_script_contains "pattern" "scripts/..."
  ```

**Recommendation:** ✅ **Add helper function**

**Rationale:**
- Reduces duplication (DRY principle)
- Improves readability
- Easier to maintain
- Better error messages

**Action Plan:**
1. Add `assert_script_contains()` to `helpers/assertions.bash`
2. Refactor existing tests to use new helper
3. Document in helpers README

**Example Implementation:**
```bash
# In helpers/assertions.bash
assert_script_contains() {
  local pattern="$1"
  local script_path="$2"
  local full_path="$PROJECT_ROOT/$script_path"
  
  run grep "$pattern" "$full_path"
  if [ "$status" -ne 0 ]; then
    echo "Expected script to contain: $pattern"
    echo "Script: $script_path"
    return 1
  fi
}
```
