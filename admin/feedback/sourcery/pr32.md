### Comment #1: Support Both Markdown Block Formats

**Issue:** Currently only handles `~~~markdown` blocks, not triple backticks (` ```markdown `)

**Why It Matters:**
- Sourcery might change their format
- Other tools might use ` ``` ` instead of `~~~`
- Makes parser more robust

**Suggested Fix:** (Provided by Sourcery)
```bash
# Extract the markdown code block content (support both ~~~markdown/~~~ and ```markdown/```)
local markdown_content=$(echo "$review_data" | sed -n '/~~~markdown/,/~~~/p' | sed '1d;$d')
if [ -z "$markdown_content" ]; then
    markdown_content=$(echo "$review_data" | sed -n '/```markdown/,/```/p' | sed '1d;$d')
fi

if [ -z "$markdown_content" ]; then
    gh_print_status "WARNING" "No markdown content found in Sourcery review"
    return 1
fi
```

**Assessment:**
- ✅ Good suggestion
- ✅ Low effort (simple fallback logic)
- ✅ Improves robustness
- 🔄 Should be fixed in **dev-toolkit** (upstream)
